# Phase 21.1 — Native API and SDK Stabilization

## Objective
Stabilize Elvaris's own application platform before adapting foreign platforms.

## Exit Criteria
- [x] Native application contract versioned (API/ABI constants)
- [x] SDK behavior documented (docs/sdk-tooling.md exists)
- [x] Native ABI smoke tests pass (user integration tests)
- [x] Package and permission behavior stable
- [ ] Architecture-independent APIs work on x86-64 and ARM64 (documented/tested as applicable)
