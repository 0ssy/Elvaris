# Elvaris v1.1 — Ordered Implementation Plan

First implementation slice: process termination and complete resource cleanup.
No new commands or storage features until lifecycle is reliable.

## Slice 1: Process ownership model
- Process table with unique ProcessId allocation
- parent/child linkage on spawn
- Ownership of address space, resource handles, kernel resources

## Slice 2: Exit and teardown
- Normal exit path
- Crash/fault termination path
- Address-space destruction + frame release
- Handle/resource cleanup with refcounts

## Slice 3: Child reaping
- Parent wait/waitpid
- Exit-status storage on zombie
- Reap removal from process table
- Orphan reparenting to init

## Slice 4: Scheduler integration
- Exclude Exited/Faulted/Reaped from scheduling
- Remove terminated processes from run queues
- Consistent state transitions (Created/Runnable/Running/Waiting/Exited/Faulted/Reaped)

## Slice 5: Resource accounting
- Per-process allocation counters
- Limits (processes, fds, memory, threads)
- Leak detection and cleanup verification

## Slice 6: Tests and diagnostics
- Lifecycle unit tests
- Parent/child integration tests
- Crash-cleanup tests
- Repeated create/exit stress tests
- QEMU end-to-end lifecycle test
