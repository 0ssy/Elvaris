# Elvaris v1.1 — Native Userland and Persistent Storage

Central success condition: A user can boot Elvaris, use the shell, create and
manipulate files, launch native programs, inspect processes, reboot, and find
the data still present.

Priorities:
1. Real process and resource management
2. Persistent storage
3. Native user-space utilities (init, shell, ls, cat, echo, mkdir, rm, cp, mv, ps, mount, dmesg)
4. One real hardware path: virtio block -> persistent filesystem -> virtio network
5. Stable native API

Compatibility layers deferred. Command-line-first identity.
