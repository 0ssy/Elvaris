# Elvaris v1.1 — Lifecycle Verification Checklist

Invariant: every process reaches one terminal state, and every process-owned
resource is released exactly once.

1. Normal exit releases all handles.
2. Faulted process releases all handles.
3. Address space destroyed exactly once.
4. Second termination attempt rejected safely.
5. Scheduler never runs terminated process.
6. Process-table entries not accidentally reusable.
7. Repeated create/terminate cycles do not leak frames/handles.
8. Cleanup occurs even if one cleanup op errors.
9. Kernel current process state valid after another process exits.
10. QEMU output confirms cleanup counters.
