# Versioning Policy (Milestone 21.1.3)

## Versions
- API version (NATIVE_API_MAJOR/MINOR/PATCH)
- ABI version (ABI_VERSION)
- Runtime version
- Package metadata version
- Compatibility-runtime version

## Rules
- Backward compatible within major version
- Breaking changes require major version bump
- Deprecation period documented
- Feature detection via version reporting
- Compatibility shims when needed
- Minimum supported runtime version tracked
